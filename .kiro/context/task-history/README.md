# Task History

Esta pasta contém os artefatos consolidados de cada task executada pelo sistema multi-agente.

Cada arquivo `task-NNN.md` é gerado automaticamente pelo hook `stop` do `qa-agent`
ao finalizar uma task, e contém:

- User Stories produzidas pelo PM
- Resultado da revisão de segurança (Reviewer)
- Resultado dos testes (QA)
- Decisões HIL registradas pelo Orquestrador
